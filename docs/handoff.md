- 2026-11-14：Task 5〜7のトースト、モーダル、プルトゥリフレッシュを実装し、各E2Eを追加した。幅900px未満ではカードを開くと一覧を隠し、「一覧へ戻る」で一覧だけに戻す。900px以上は2列を保つ。見本ファイルの存在確認のスキップも外した。
- 検証：`npm run test:unit`は11件すべて成功、スキップ0件。3つのデモの構文検査も成功。`npm run test:e2e -- --list`はmac・iphoneの計102件を読み込んだ。回帰テストの実装前、デモの実装前、実装後の全件実行を試したが、いずれもwebServerが`PermissionError: [Errno 1] Operation not permitted`で起動せず、テスト本体は実行0件。E2Eの失敗→成功と両プロジェクトでの全件成功は未確認。
